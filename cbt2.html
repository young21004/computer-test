2026년 컴퓨터활용능력 2급 기출문제 Ⅱ

제1과목 컴퓨터 일반
1. 다음 중 Windows에서 [Winkey] 와 함께 사용하는 바로 가기 키에 대한 설명으로 틀린 것은?
[해설]
  • [Winkey] + [E]는 파일 탐색기를 실행하는 바로 가기 키입니다. ‘실행’ 창을 표시하는 바로 가기 키는 [Winkey] + [R]입니다.
2. 다음 중 인터넷 주소 체계인 IPv6에 대한 설명으로 옳지 않은 것은?
[해설]
  • IPv6은 IPv4와의 호환성 및 주소의 확장성, 융통성, 연동성이 뛰어납니다.
3. 다음 중 한글 Windows 10의 [메모장]에 대한 설명으로 옳지 않은 것은?
[해설]
  • 메모장에서는 그림, 차트 등의 OLE 개체를 삽입할 수 없습니다.
  • 특별한 서식이 필요 없는 간단한 텍스트(ASCII 형식) 파일을 작성할 수 있는 문서 작성 프로그램
  • 텍스트(.TXT) 형식의 문서만 열거나 저장할 수 있으며, 문서 전체에 대해서만 글꼴의 종류, 속성, 크기를 변경할 수 있음
  • 글꼴 색 변경은 안 됨
  • 자동 줄 바꿈, 찾기, 시간/날짜 삽입 등의 기능을 제공함
  • 문서의 첫 행 맨 왼쪽에 대문자로 ‘.LOG’라고 입력하면 메모장을 열 때마다 현재의 시간과 날짜를 문서의 끝에 표시함
  • F5키를 눌러 원하는 위치에 현재의 시간과 날짜를 입력 할 수 있음
4. 다음 중 한글 Windows 10에서 하드디스크를 포맷하기 위한 [포맷] 창에서 설정 가능한 항목으로 옳지 않은 것은?
[해설]
  • ‘포맷’ 대화상자에서 ‘파티션 제거’는 수행할 수 없습니다. ‘포맷’ 대화상자에서 설정할 수 있는 항목에는 용량, 파일 시스템, 할당 단위 크기, 볼륨 레이블, 빠른 포맷 등이 있습니다.
5.다음 중 컴퓨터에서 문자 데이터를 표현하는 방법으로 옳지 않은 것은?
[해설]
  • 해밍 코드(Hamming Code)는 문자 데이터를 표현하기 위해 사용하는 코드가 아닙니다. 해밍코드는 에러 검출 및 교정이 가능한 코드입니다.
  • BCD 코드 : 6비트로 구성, 26=64개의 문자, 영문 소문자를 표현하지 못함
  • ASCII 코드 : 7비트로 구성, 27=128개의 문자, 미국 표준 코드, 데이터 통신용, 개인용 컴퓨터에 사용
  • EBCDIC 코드 : 8비트로 구성, 28=256개의 문자, 대형 컴퓨터에서 사용
  • 유니코드 : 전 세계의 모든 문자를 2바이트로 표현할 수 있는 국제 표준 코드로, 정보 처리/정보 교환용으로 사용함
6. 다음 중 컴퓨터에서 사용하는 일반 하드디스크에 비하여 속도가 빠르고 기계적 지연이나 에러의 확률 및 발열 소음이 적으며, 소형화, 경량화할 수 있는 하드디스크 대체 저장장치는?
[해설]
  • 문제에 제시된 내용은 SSD(Solid State Drive)에 대한 설명입니다.
  • 하드디스크를 대체할 무소음, 저전력, 소형화, 경량화, 고효율의 속도를 지원하는 차세대 반도체 보조 기억 장치이다.
  • HDD보다 외부로부터의 충격에 강하며, 기계적인 디스크가 아닌 반도체 메모리에 데이터를 저장하므로 배드 섹터(Bad Sector)가 생기지 않는다.
  • HDD에 비해 저장 용량당 가격 면에서 SSD가 더 비싸다.
7. 다음 중 프로그램이 실행될 때 발생하는 메인 메모리 부족 문제를 보완하기 위해 하드디스크의 일부를 메인 메모리처럼 사용하게 하는 메모리 관리 기법을 의미하는 것은?
[해설]
  • 보조기억장치의 일부를 주기억장치처럼 사용하는 메모리 기법을 가상 메모리(Virtual Memory)라고 합니다.
  • 가상 메모리(Virtual Memory)
    1) 보조 기억 장치의 일부, 즉 하드디스크의 일부를 주기억 장치처럼 사용하는 메모리 사용 기법으로, 기억 장소를 주기억 장치의 용량으로 제한하지 않고, 보조 기억 장치까지 확대하여 사용한다.
    2) 기억 공간의 확대에 목적이 있다.(처리 속도 향상 아님)
    3) 가상 기억 장치로는 임의 접근이 가능한 자기 디스크를 많이 사용한다.
  • 캐시 메모리(Cache Memory)
    1) 속도가 빠른 CPU와 상대적으로 속도가 느린 주기억장치 사이에 있는 고속의 버퍼 메모리.
    2) 자주 참조되는 데이터나 프로그램을 메모리에 저장한다.
    3) 주로 접근 속도가 빠른 정적 램(SRAM)을 사용하며, 주기억장치에 비해 용량이 적다.
  • 연관 메모리(Associative Memory)
    1) 저장된 내용의 일부를 이용하여 기억 장치에 접근하여 데이터를 읽어오는 기억 장치이다.
    2) CAM(Content Addressable Memory) 이라고도 한다.
8. 다음 중 멀티미디어와 관련하여 동영상 전문가 그룹에 의해서 제안된 비디오 또는 오디오 압축에 관한 일련의 표준으로 옳은 것은?
[해설]
  • 동영상 전문가 그룹에서 제정한 동영상 압축 기술에 대한 국제 표준 규격은 MPEG입니다. MPEG과 관련해서는 MPEG 규격에 대한 문제가 종종 출제되고 있으니 함께 정리해 두세요
  • XML
    HTML의 단점을 보완하고 클라이언트의 복잡한 데이터 처리를 쉽게 할 수 있으며, 자신의 목적에 맞는 태그를 정의할 수 있는 마크업 언어
  • JPEG
    1) 정지 영상 압축 기술에 관한 국제 표준화 규격으로 20:1 정도로 압축할 수 있는 형식
    2) 24비트 컬러 사용으로 16,777,216(224)가지의 색을 표현할 수 있다.
    3) 손실 압축 기법과 비손실 압축 기법을 사용한다.
9. 다음 중 컴퓨터 바이러스의 예방법으로 가장 거리가 먼 것은?
[해설]
  • 전자우편에 첨부된 파일은 바이러스 검사를 수행한 후 저장하여 사용해야 합니다. 컴퓨터 바이러스 감염에 대한 예방법을 묻는 문제가 종종 출제되니 나머지 보기를 통해 정리하세요.
10. 다음 중 컴퓨터를 이용한 가상 현실(Virtual Reality)에 관한 설명으로 옳은 것은?
[해설]
  • 컴퓨터 그래픽 기술과 3차원 기법을 통해 만들어낸 가상 세계에서 여러 다른 경험을 체험할 수 있도록 하는 모든 기술을 가상현실(Virtual Reality)라고 합니다. 이 문제에서는 가상 현실(Virtual Reality)의 개념이 무엇인지만 정확히 알아두고 넘어가세요.
11. USB 포트에 대한 설명으로 옳지 않은 것은?
[해설]
  • 한 번에 8비트의 데이터를 동시에 전송하는 것은 병렬 포트입니다.
  • USB
    1) 허브(Hub)를 사용하면 최대 127개의 주변기기의 연결이 가능하다.
    2) 기존 직렬, 병렬, PS/2 포트 등을 하나의 포트로 대체하기 위한 범용 직렬 버스 장치
    3) 직렬 포트나 병렬 포트보다 빠른 속도로 데이터 전송한다.
    4) 핫 플러그 인, 플러그 앤 플레이를 지원한다.
12. 다음 중 인터넷에서 웹 서버와 사용자의 인터넷 브라우저 사이에 하이퍼텍스트 문서를 전송하기 위해 사용되는 통신 규약은?
[해설]
  • 하이퍼텍스트 문서를 전송하기 위해 사용하는 프로토콜은 HTTP(HyperText Transfer Protocol)입니다.
  • SMTP : 전자 우편을 송신하기 위한 프로토콜
  • TCP
    ① 메시지를 송·수신자의 주소와 정보로 묶어 패킷 단위로 분류
    ② 전송 데이터의 흐름을 제어하고 데이터의 에러 유무 검사
    ③ OSI 7 계층 중 전송 계층에 해당함
  • FTP : 파일 송수신 프로토콜
13. 다음 중 사용자의 기본 설정을 사이트가 인식하도록 하거나, 사용자가 웹 사이트로 이동할 때마다 로그인해야 하는 번거로움을 생략할 수 있도록 사용자 환경을 향상시키는 것은?
[해설]
  • 인터넷 접속 시 매번 아이디와 비밀번호를 넣지 않고 자동으로 접속할 수 있게 해주는 작은 파일을 쿠키라고 합니다.
14. 다음 중 컴퓨터 범죄 예방에 대한 설명으로 옳지 않은 것은?
[해설]
  • 패스워드는 해킹 당할 수 있으므로 정기적으로 변경하는 것이 좋습니다. 컴퓨터 범죄 예방은 상식적인 수준에서 생각하면 맞힐 수 있는 문제가 주로 출제됩니다.
15. 다음 중 멀티미디어의 특징에 대한 설명으로 옳지 않은 것은?
[해설]
  • 멀티미디어는 그래픽, 비디오, 오디오 등 각 미디어별로 다양한 파일 형식이 있어 용도에 맞는 멀티미디어의 제작이 용이합니다.
  • 멀티미디어의 특징
    1) 디지털화 : 다양한 데이터 형식을 컴퓨터가 인식할 수 있도록 디지털로 변환
    2) 쌍방향성 : 사용자와 제공자 간에 서로 정보를 주고받음
    3) 비선형성 : 사용자의 선택에 따라 정보를 처리함
    4) 통합성 : 문자, 그래픽, 사운드, 동영상, 애니메이션 등의 다양한 매체를 통합함
16. 다음 중 인터넷 홈페이지 제작 언어로 옳지 않은 것은?
[해설]
  • AIDA는 CPU, 메인보드, 램, 그래픽 카드, 사운드카드 등 PC에 설치되어 있는 모든 하드웨어 정보를 확인할 때 사용하는 유틸리티 프로그램입니다.
  • 객체 지향 언어에 C++, Actor, SmallTalk, JAVA 등이 있다.
17. 다음 중 컴퓨터에서 사용하는 하드디스크의 파티션에 대한 설명으로 옳지 않은 것은?
[해설]
  • 각각의 파티션에는 서로 다른 운영체제를 설치할 수 있습니다.
  • 파티션
    파티션은 하나의 물리적인 하드디스크를 여러 개의 논리적인 영역으로 나누는 작업으로, 기본 파티션과 확장 파티션이 있다.
    1) 운영체제에서는 파티션이 하나의 드라이브로 인식된다.
    2) 하나의 파티션에는 한 종류의 파일 시스템만 사용할 수 있다.
    3) 파티션을 설정한 후에는 반드시 포맷을 해야 사용할 수 있다.
    4) 파티션의 분할 및 병합은 '디스크 관리'에서 수행 할 수 있다.
  • 포맷
    디스크의 포맷은 디스크를 초기화(트랙과 센터 형성)하여 사용 가능한 상태로 만들어 주는 작업을 말한다.
    1) 디스크를 사용하기 위해서는 먼저 초기화 작업인 포맷을 해야 한다.
    2) 사용하던 디스크를 포맷할 경우 기존 데이터는 모두 삭제 된다.
    3) 포맷하려는 디스크의 데이터를 사용하는 중이라면 포맷 할 수 없다.
    4) 빠른 포맷 : 디스크의 불량 섹터는 검출하지 않고, 디스크의 모든 파일을 삭제한다.
18. 다음 중 한글 Windows 10에서 프린터 설치에 관한 설명으로 옳지 않은 것은?
[해설]
  • 네트워크 프린터를 선택한 경우에는 연결할 프린터의 포트가 자동으로 지정됩니다.
  • 프린터의 설치 및 제거
    1) [제어판]-[하드웨어 및 소리]-[장치 및 프린터]-[프린터 추가]를 클릭함.
    2) [시작]-[설정]-[장치]-[프린터 및 스캐너]-[프린터 또는 스캐너 추가]를 클릭함.
    3) 프린터 추가에서 PC에서 추가할 장치 또는 프린터를 선택한다.
    4) Windows에서는 USB 프린터는 연결하면 자동으로 설치되므로 로컬 프린터 추가는 USB 프린터를 사용하지 않는 경우에만 선택한다.
    5) 프린터의 유형
    ① 로컬 프린터 : 직접 PC와 연결된 프린터
    ② 네트워크, 무선, Bluetooth 프린터 : 네트워크 상에 연결된 프린터나 무선, 근거리 무선 접속이 지원되는 프린터
    6) 로컬 프린터를 설치할 경우 프린터의 포트, 제조업체, 모델명, 이름, 공유, 기본 프린터 등을 직접 지정해야 하지만 네트워크 프린터를 설치할 경우 별다른 설정 없이 네트워크에 연결되어 있는 프린터 중 사용할 프린터만 선택하면 된다.
    7) 프린터를 제거하려면 프린터 아이콘을 클릭한 다음 [장치 제거]를 클릭하거나 바로 가기 메뉴의 [장치 제거]를 클릭한다.
  • 기본 프린터
    1) 프로그램에서 사용할 프린터를 지정하지 않고 인쇄 명령을 선택했을 때 컴퓨터가 자동으로 문서를 보내는 프린터
    2) 현재 인쇄를 담당하고 있는 프린터를 말하며, 오직 1개만 설정할 수 있다.
    3) 기본 프린터로 설정된 프린터 아이콘에는 표시가 나타난다.

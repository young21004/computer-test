2026년 컴퓨터활용능력 2급 기출문제

제1과목 컴퓨터 일반
1. 다음 중 컴퓨터에서 사용되는 바이트(Byte)에 대한 설명으로 옳지 않은 것은?
[해설]
  • 컴퓨터에서 각종 명령을 처리하는 기본 단위는 단어(Word)입니다. 바이트(Byte)는 문자를 표현하는 기본 단위이자 기억장치 용량의 기본 단위입니다.
2. 다음 중 한글 Windows 10의 '작업 관리자' 대화상자에서 수행할 수 있는 작업으로 옳지 않은 것은?
[해설]
  • 사용자 계정의 추가 및 삭제는 [설정] → [계정] 또는 [제어판] → [사용자 계정]에서 수행할 수 있습니다. 작업 관리자에서는 현재 접속 중인 사용자의 세션 관리(로그오프 등)나 프로세스 확인만 가능합니다.
3. 다음 중 인터넷을 이용한 자체 검색 기능은 가지고 있지 않으나, 한 번의 검색어 입력으로 다른 검색 엔진에 검색을 의뢰해 그 결과만 보여주는 검색 엔진은?
[해설]
  • 메타 검색 엔진(Meta Search Engine)은 자체 데이터베이스를 가지고 있지 않고, 여러 검색 엔진에 검색을 의뢰하여 그 결과를 통합하여 보여주는 검색 엔진입니다.
4. 다음 중 한글 Windows 10의 [설정] → [접근성]에서 설정할 수 없는 기능은?
[해설]
  • 다중 디스플레이 설정은 [설정] → [시스템] → [디스플레이]에서 수행합니다.
5. 다음 중 컴퓨터 바이러스에 대한 설명으로 가장 적절하지 않은 것은?
[해설]
  • 전자우편(이메일)의 첨부 파일은 바이러스가 유포되는 가장 주요한 경로 중 하나입니다.
6. 다음 중 한글 Windows 10에서 '컴퓨터 이름'을 변경하는 방법으로 옳은 것은?
[해설]
  • 컴퓨터 이름은 [제어판] → [시스템 및 보안] → [시스템] 메뉴 또는 Windows [설정] → [시스템] → [정보]에서 변경할 수 있습니다.
7. 다음 중 한글 Windows 10에서 하드디스크를 포맷하기 위한 [포맷] 창에서 설정 가능한 항목으로 옳지 않은 것은?
[해설]
  • [포맷] 대화상자에서는 용량, 파일 시스템, 할당 단위 크기, 볼륨 레이블, 포맷 옵션(빠른 포맷) 등을 설정할 수 있으며, 파티션 제거는 [컴퓨터 관리] → [디스크 관리]에서 가능합니다.
8. 한글 Windows 10의 [휴지통]에 관한 설명으로 옳지 않은 것은?
[해설]
  • [휴지통 비우기]를 실행하면 휴지통에 들어 있는 파일이 완전히 삭제되어 휴지통에서 일반적인 방법으로 복구할 수 없습니다.
9. 다음 중 라디오와 같이 한 쪽은 송신만, 다른 한 쪽은 수신만 가능한 정보 전송 방식은?
[해설]
  • 단방향 통신(Simplex): 한쪽 방향으로만 데이터 전송이 가능한 방식 (예: TV, 라디오 방송).
10. 다음 중 의류, 시계, 안경 등 사람이 몸에 착용하고 다닐 수 있는 컴퓨터를 의미하는 것은?
[해설]
  • 착용형 컴퓨터(Wearable Computer)는 의류나 안경, 시계처럼 몸에 착용하거나 지니고 다닐 수 있도록 제어 장치 및 입력 장치를 소형화/통합화한 컴퓨터입니다.
11. 다음 중 사용자의 기본 설정을 사이트가 인식하도록 하거나, 사용자가 웹 사이트로 이동할 때마다 로그인해야 하는 번거로움을 생략할 수 있도록 사용자 환경을 향상시키는 것은?
[해설]
  • 쿠키(Cookie)는 인터넷 웹사이트 방문자의 정보를 사용자의 컴퓨터에 저장하여 보관하는 소규모 텍스트 파일입니다.
12. 다음 중 전자우편과 관련하여 스팸(SPAM)에 관한 설명으로 옳은 것은?
[해설]
  • 스팸 메일(Junk Mail)은 수신자의 동의 없이 다량으로 무차별 송신되는 광고성 전자우편입니다.
13. 다음 중 컴퓨터에서 사용하는 레이저 프린터에 관한 설명으로 옳지 않은 것은?
[해설]
  • 드럼식, 체인식, 밴드식은 충격식 프린터 중 대형 컴퓨터에서 사용하는 Line Printer(라인 프린터)의 종류입니다.
14. 다음 중 모든 사물을 네트워크로 연결하여 인간과 사물, 사물과 사물 간에 언제 어디서나 서로 소통할 수 있게 하는 새로운 정보통신 환경을 의미하는 것은?
[해설]
  • 사물 인터넷(IoT, Internet of Things): 각종 사물에 센서와 통신 기능을 내장하여 인터넷에 연결하는 기술입니다.
15. 다음 중 하이퍼텍스트(Hypertext)에 대한 설명으로 옳지 않은 것은?
[해설]
  • 텍스트뿐만 아니라 그래픽, 사운드, 동영상 등 멀티미디어 정보를 링크로 연결한 것을 하이퍼미디어(Hypermedia)라고 합니다.
16. 다음 중 Windows에서 실행중인 프로그램 사이의 작업 전환을 위한 바로 가기 키는?
[해설]
  • [Alt] + [Tab]: 작업 전환(실행 중인 앱 전환)
  • [Alt] + [Enter]: 선택한 항목의 속성 창 열기
  • [Alt] + [F4]: 활성 창 닫기 또는 프로그램 종료
17. 다음 중 비트맵 이미지를 확대하였을 때 이미지의 경계선이 매끄럽지 않고 계단 형태로 나타나는 현상을 의미하는 용어는?
[해설]
  • 앨리어싱(Aliasing): 비트맵 이미지를 확대할 때 이미지 가장자리가 매끄럽지 못하고 계단 현상이 발생하는 현상입니다. (이를 완화하는 기술은 안티앨리어싱이라고 합니다.)
18. 다음 중 디지털 컴퓨터와 아날로그 컴퓨터의 차이점에 관한 설명으로 옳은 것은?
[해설]
  • 아날로그 컴퓨터는 연속적인 데이터(전압, 전류 등)를 입력받아 미적분 연산을 주로 수행하며 특수 목적용입니다.
  • 디지털 컴퓨터는 비연속적인 데이터(숫자, 문자 등)를 논리 회로를 통해 산술 및 논리 연산으로 처리하며 범용으로 사용됩니다.
19. 다음은 인터럽트(Interrupt)에 대한 설명이다. 잘못된 것은?
[해설]
  • 트랩(Trap)은 **내부 인터럽트**(예: 0으로 나누기, 오버플로, 잘못된 명령어 사용 등)를 가리키는 용어입니다.
20. 다음 중 인터넷을 수동으로 연결하기 위하여 지정해야 할 TCP/IP 구성 요소로 옳지 않은 것은?
[해설]
  • TCP/IP 수동 설정 시 지정해야 할 기본 항목은 IP 주소, 서브넷 마스크, 기본 게이트웨이, DNS 서버 주소입니다. 어댑터 주소(MAC 주소)는 랜카드 고유의 하드웨어 주소로 지정하지 않습니다.
제2과목 스프레드시트 일반
21. 다음 중 날짜 및 시간 데이터에 관한 설명으로 옳지 않은 것은?
[해설]
  • 날짜 및 시간 데이터는 수치 데이터로 취급되므로 기본적으로 **오른쪽 맞춤**으로 정렬됩니다.
22. '성적1' 필드와 '성적2' 필드의 값이 모두 90 이상이면 '진급여부' 필드에 "진급", 하나만 90 이상이면 "대기", 나머지는 공백으로 표시하는 수식으로 옳은 것은?

[해설]
  • COUNTIF(B2:C2, ">=90")가 2(두 과목 모두 90 이상)이면 "진급", 1(한 과목만 90 이상)이면 "대기", 그 외에는 ""(공백)을 반환하는 번이 올바릅니다.
23. 다음 중 여러 워크시트를 선택하여 그룹으로 설정한 경우에 대한 설명으로 옳지 않은 것은?
[해설]
  • 시트가 그룹으로 설정된 상태에서 [이동/복사] 명령을 실행하면 그룹으로 묶인 **모든 시트**가 함께 이동/복사됩니다.
24. 다음 중 매크로 작성에 대한 설명으로 옳은 것은?
[해설]
  • 엑셀의 기본 바로 가기 키도 지정할 수 있으며, 이 경우 매크로 바로 가기 키가 우선 적용됩니다.
  • 바로 가기 키에 대문자를 입력하면 [Shift]가 자동으로 덧붙습니다. ([Ctrl]+[Shift]+영문대문자)
  • VBA 편집기를 사용하여 매크로 코드를 직접 수정할 수 있습니다.
25. 다음 중 셀의 이동과 복사에 대한 설명으로 옳지 않은 것은?
[해설]
  • 테두리를 드래그할 때 **[Ctrl]**을 누른 채 드래그해야 셀 복사가 이루어집니다. [Shift]를 누른 채 드래그하면 셀 사이에 이동하여 삽입됩니다.
26. 다음 중 채우기 핸들에 대한 설명으로 옳은 것은?
[해설]
  • 문자+숫자 혼합 셀을 그냥 드래그하면 숫자가 1씩 증가하지만, [Ctrl]을 누른 채 드래그하면 그대로 복사됩니다.
27. 다음 중 시나리오에 관한 설명으로 옳지 않은 것은?
[해설]
  • 번 설명은 '부분합' 기능에 대한 설명입니다.
28. 아래 그림을 [데이터 계열 서식] 메뉴를 이용하여 수정하고자 할 때, 다음 중 설명이 옳지 않은 것은?

[해설]
  • [간격 너비]를 늘리면 막대와 막대 사이의 여백이 넓어지므로, 상대적으로 각 **막대의 너비는 좁아집니다**.
29. 다음 중 데이터 통합에 관한 설명으로 옳지 않은 것은?
[해설]
  • '원본 데이터에 연결' 기능은 **서로 다른 워크시트** 또는 **다른 통합 문서**에 있는 원본 데이터를 통합할 때 설정할 수 있으며, 동일한 워크시트 내의 데이터에 연결하려는 경우 사용할 수 없습니다.
30. 다음 중 '페이지 설정' 대화상자에 대한 설명으로 옳지 않은 것은?
[해설]
  • '페이지 설정' 대화상자에서는 용지 방향, 여백, 머리글/바닥글, 시트 옵션(눈금선, 오류 표시 등)을 설정하며, 사용할 프린터를 변경하는 것은 [인쇄] 화면에서 지정합니다.
31. 다음 중 페이지 나누기에 대한 설명으로 옳지 않은 것은?
[해설]
  • 행 높이나 열 너비를 변경하면 한 페이지에 인쇄되는 범위가 바뀌므로 자동 페이지 나누기 구분선의 위치도 함께 **변경됩니다**.
32. 다음 중 하나의 계열만 표시할 수 있는 차트는?
[해설]
  • 원형 차트(Pie Chart)는 항상 하나의 데이터 계열만 표현할 수 있는 특징이 있습니다. (여러 계열을 표현하려면 도넛형 차트 등을 사용합니다.)
33. 다음 중 매크로에 관한 설명으로 옳지 않은 것은?
[해설]
  • 현재 셀의 위치를 기준으로 매크로가 실행되도록 하려면 [상대 참조로 기록]을 선택한 후 매크로를 기록해야 합니다. (기본값은 절대 참조 기록)
34. 다음 중 원본 데이터에 사용자 지정 서식을 적용하였을 때의 표시 결과가 옳은 것은?
[해설]
  • 2021년 3월 29일은 월요일이 맞으며, dddd(요일 풀네임, Monday), mmm(월 축약형, Mar), dd(일, 29), yyyy(연도, 2021) 서식이 바르게 적용되었습니다.
35. 아래 워크시트에서 [B2:D6] 영역을 참조하여 [C8] 셀에 표시된 바코드에 대한 단가를 [C9] 셀에 표시하였다. 다음 중 [C9] 셀의 수식으로 옳은 것은?

[해설]
  • 열 방향 테이블에서 찾기 위해 VLOOKUP 함수를 사용하며, 검색값 C8, 범위 $B$2:$D$6, 가져올 열 번호 3(단가), 정확히 일치 0(FALSE)을 전달하는 번이 정답입니다.
36. 다음 중 '셀 항목 자동 완성' 기능에 대한 설명으로 옳지 않은 것은?
[해설]
  • 문자와 숫자가 혼합된 텍스트 항목 등 문자 데이터가 포함된 경우라면 폭넓게 적용되므로, '한글이나 영어로만 구성된 항목에 적용된다'는 번은 옳지 않습니다.
37. 다음 중 입력한 수식에서 발생한 오류 메시지와 그 발생 원인으로 옳지 않은 것은?
[해설]
  • #REF!는 셀 참조가 유효하지 않을 때(삭제된 셀을 참조하거나 지워진 범위를 참조할 때) 발생하는 오류입니다.
38. 다음 중 차트에 대한 설명으로 옳지 않은 것은?
[해설]
  • 방사형 차트는 많은 데이터 계열의 합계 값을 비교할 때 다평면 거미줄 형태로 표시하는 독자적인 차트 종류이며, 분산형 차트의 일종이 아닙니다. (거품형 차트 등이 분산형 차트의 확장 형태입니다.)
39. 다음 중 워크시트 작업 및 관리에 대한 설명으로 옳지 않은 것은?
[해설]
  • 열 머리글 경계선을 더블클릭하면 해당 열에 입력된 데이터 중 가장 긴 내용에 맞춰 **열 너비가 자동 맞춤**됩니다. 기본값으로 되돌아가지는 않습니다.
40. 다음 중 자동 필터에 대한 설명으로 옳지 않은 것은?
[해설]
  • 엑셀의 기본 정렬 기능은 기본적으로 영문 대소문자를 구분하지 않으며, 구분하여 정렬하려면 [정렬 옵션]에서 '대/소문자 구분'을 별도로 체크해야 합니다.

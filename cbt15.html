제1과목 컴퓨터 일반
1. 다음 중 한글 Windows 10에서 '명령 프롬프트' 창을 표시하기 위해 '실행' 창에 입력해야 하는 것은?
[해설]
'명령 프롬프트' 창을 표시하기 위해 '실행' 창에 입력해야 하는 것은 cmd입니다.
• ping: 원격 컴퓨터가 현재 네트워크에 연결되어 정상적으로 작동하고 있는지 알아보는 서비스
• tracert: 인터넷 서버까지의 경로를 추적하는 명령어
2. 핸드폰, PDA, 노트북과 같은 휴대 가능한 장치들 간의 근거리 무선 통신을 가능하게 해주는 통신 방식은?
[해설]
휴대 가능한 장치들 간의 근거리 무선 통신을 가능하게 해주는 통신 방식은 블루투스(BlueTooth)입니다.
3. 다음 중 프로그램이 실행될 때 발생하는 메인 메모리 부족 문제를 보완하기 위해 하드디스크의 일부를 메인 메모리처럼 사용하게 하는 메모리 관리 기법을 의미하는 것은?
[해설]
보조기억장치(하드디스크)의 일부를 주기억장치처럼 사용하는 메모리 기법을 가상 메모리(Virtual Memory)라고 합니다.
4. 다음 중 컴퓨터 범죄의 예방 방법으로 가장 적절하지 않은 것은?
[해설]
게시판에 업로드된 프로그램은 바이러스에 감염되었을 수 있으므로 반드시 백신 프로그램으로 검사한 후 사용하는 것이 좋습니다.
5. 다음 중 인터넷에 대한 설명으로 적절하지 않은 것은?
[해설]
인터넷은 전 세계의 컴퓨터망이 연결된 광범위한 통신망으로, 특정 상업용 네트워크가 아니며 중앙통제기구도 존재하지 않습니다.
6. 다음 중 한글 Windows 10의 인쇄 기능에 대한 설명으로 옳지 않은 것은?
[해설]
인쇄 중인 작업도 언제든지 취소하거나 일시 중지할 수 있습니다.
7. 다음 중 컴퓨터에서 사용하는 각 기억장치의 접근 속도가 빠른 것에서 느린 순서로 옳게 나열된 것은?
[해설]
접근 속도가 빠른 순서는 레지스터 → 캐시 메모리 → 주기억장치 → 보조기억장치입니다[cite: 8, 12].
8. 다음 중 Windows 10의 [설정] → [개인 설정]에 관한 설명으로 옳지 않은 것은?
[해설]
화면이 꺼지는 시간은 [설정] → [시스템] → [전원 및 절전] 메뉴에서 설정합니다.
9. 다음 중 네트워크와 관련하여 Ping 서비스에 대한 설명으로 옳은 것은?
[해설]
Ping은 네트워크 연결 및 대상 컴퓨터의 작동 여부를 점검하는 서비스입니다. (1번 Telnet, 3번 Tracert, 4번 Finger)
10. 다음 중 데이터가 발생되는 즉시 처리되어 결과를 바로 확인할 수 있는 시스템으로, 은행이나 여행사의 좌석 예약 조회 서비스 등에 이용되는 것은?
[해설]
데이터 발생 즉시 처리 결과를 얻는 방식은 실시간 처리 시스템(Real-Time Processing System)입니다.
11. USB 포트에 대한 설명으로 옳지 않은 것은?
[해설]
USB(Universal Serial Bus)는 직렬 인터페이스이므로 데이터가 한 번에 1비트씩 직렬 전송됩니다. 8비트 동시 전송은 병렬 포트의 방식입니다.
12. 다음 중 컴퓨터에서 사용하는 유니코드(Unicode)에 관한 설명으로 옳은 것은?
[해설]
유니코드는 모든 문자를 통일하여 2Byte(16Bit)로 표현하는 국제 표준 코드입니다.
13. 다음 중 유틸리티 프로그램에 대한 설명으로 적절하지 않은 것은?
[해설]
유틸리티 프로그램은 시스템 관리 및 사용 편의를 돕는 프로그램으로, 시스템 작동에 반드시 필요한 필수 소프트웨어(운영체제 등)는 아닙니다.
14. 다음 중 인터넷 주소 체계에 대한 설명으로 옳지 않은 것은?
[해설]
인터넷 연결에는 반드시 IP 주소가 필요합니다. 도메인 네임은 숫자로 된 IP 주소를 사람이 쉽게 기억할 수 있도록 문자로 변환한 주소 체계입니다.
15. 다음 중 애니메이션에서의 모핑(Morphing) 기법에 대한 설명으로 옳은 것은?
[해설]
모핑(Morphing)은 하나의 사물/이미지가 다른 사물/이미지로 자연스럽게 변화하는 기법입니다. (1번 셀 애니메이션, 3번 키 프레임 애니메이션, 4번 클레이메이션)
16. 다음 중 한글 Windows 10의 드라이브 조각 모음 및 최적화 기능에 관한 설명으로 옳지 않은 것은?
[해설]
드라이브 조각 모음은 단편화를 제거하여 접근 속도와 효율성을 향상시킬 뿐, 용량 자체가 증가하지는 않습니다.
17. 다음 중 폴더의 [속성] 창에 대한 설명으로 옳지 않은 것은?
[해설]
폴더의 [속성] 창에서는 저장 위치를 확인만 할 수 있고 수정/변경할 수는 없습니다.
18. 다음 중 컴퓨터의 연산장치에 있는 누산기(Accumulator)에 관한 설명으로 옳은 것은?
[해설]
누산기(AC)는 연산 장치(ALU) 내에서 연산 결과를 일시적으로 저장하는 레지스터입니다. (3번 명령 레지스터, 4번 해독기)
19. 다음 중 컴퓨터를 관리하는 효율적인 방법으로 옳지 않은 것은?
[해설]
모든 파티션을 제거하면 하드디스크의 전체 데이터가 파기되므로 올바른 문제 해결 방법이 아닙니다.
20. 다음 중 한글 Windows 10에서 프린터 설치에 관한 설명으로 옳지 않은 것은?
[해설]
네트워크 프린터를 연결할 때는 사용 가능한 포트가 자동으로 포트 설정되어 연결됩니다.

21. 다음 중 아래와 같이 조건을 설정한 고급 필터의 실행 결과에 대한 설명으로 옳은 것은?

22. 다음 중 매크로 기록에 관한 설명으로 옳지 않은 것은?
[해설]
매크로 이름의 첫 글자는 반드시 문자(한글/영문)나 밑줄(_)로 시작해야 하며 숫자로 시작할 수 없습니다.
23. [홈] → [편집] → [찾기 및 선택] → [찾기]를 선택하여 표시된 대화상자의 찾을 내용에 '삼?주식회사'를 입력하였을 경우 검색되는 대상에 대한 설명으로 옳은 것은? (단, [전체 셀 내용 일치] 옵션 설정)
[해설]
와일드카드 '?'는 한 글자를 의미하므로 '삼' + (1글자) + '주식회사'로 이루어진 총 6글자 데이터가 추출됩니다.
24. 수식 '=VLOOKUP(LARGE(A2:A9, 4), A2:F9, 5, 0)'의 실행 결과로 옳은 것은?

[해설]
1. LARGE(A2:A9, 4): 번호 열(1~8) 중 4번째로 큰 값은 5입니다.
2. VLOOKUP(5, A2:F9, 5, 0): 번호가 5인 행(한공주)에서 5번째 열(수학)의 값인 88을 반환합니다.

26. 다음 중 각 차트 종류에 대한 설명으로 적절하지 않은 것은?

주식형 차트는 3차원(3D) 차트 형태로 작성할 수 없습니다.
27. 다음 중 [페이지 설정] 대화상자의 [시트] 탭에 대한 설명으로 옳지 않은 것은?

30. 다음 중 [부분합] 대화상자의 각 항목 설정에 대한 설명으로 옳지 않은 것은?

기존 부분합을 유지한 채 새 부분합을 추가하려면 '새로운 값으로 대치' 체크 항목을 **해제**해야 합니다.
31. 다음 중 틀 고정 및 창 나누기에 대한 설명으로 옳지 않은 것은?

33. 다음 중 인쇄에 대한 설명으로 옳은 것은?

차트를 클릭하여 선택한 후 인쇄를 실행하면 해당 차트만 단독 인쇄할 수 있습니다.

37. 다음 중 참조의 대상 범위로 사용하는 이름에 대한 설명으로 옳은 것은?
